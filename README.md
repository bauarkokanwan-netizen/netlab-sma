# NetLab SMA

Simulator jaringan sederhana untuk praktik anak SMA.

## Fitur
- Drag & drop PC, Switch, Router
- Hubungkan perangkat dengan kabel
- Konfigurasi IP address
- Simulasi ping sederhana
- Materi dan tugas praktikum

## Menjalankan Project

```bash
npm install
npm run dev
```

## Deploy
Upload ke Vercel langsung dari GitHub.
